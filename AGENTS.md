## Language for written output
- Text written into files, issues, comments, docs and commit messages is
  in English, even when my notes are in Ukrainian. Translate faithfully.
- Write plain international English, as used in EU institutions and
  international teams: short, clear sentences for non-native readers.
  No British or American idioms, slang or colloquialisms.
- Use British spelling in ordinary prose (colour, organise, behaviour).
- Never change technical terms, code identifiers, commands, file names,
  API or tool names, or established industry spellings. Keep them exactly
  as they are.
- Chat replies to me follow the language I write in.
